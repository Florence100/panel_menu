# Menu with Visual Effects

A creative navigation menu with eye‑catching visual effects.  
Built with vanilla HTML, CSS, and JavaScript – no external libraries.  
Perfect for portfolios, landing pages, or any project that needs a memorable UI.

**Live Demo:** [https://panel-menu.netlify.app/](https://panel-menu.netlify.app/)

---

## Core technologies

- **HTML5** – semantic markup, accessibility attributes.
- **CSS3** – Flexbox/Grid, custom properties, `@keyframes`, transitions, filters.
- **Vanilla JavaScript (ES6)** – event handling, animation, class manipulation, coordinate calculations for parallax.
